# Remote Window — 배포 파일

내 Windows PC 를 폰·다른 PC 에서 보고 조작하는 **Remote Window** 의 설치 파일을 올리는 곳입니다.
최신 버전은 오른쪽 **Releases** 에 있습니다.

| 파일 | 설명 |
|---|---|
| `RemoteWindow-Setup-<버전>.exe` | Windows 설치 프로그램 (관리자 권한 불필요) |
| `RemoteWindow-<버전>.apk` | 안드로이드 앱 |
| `*.sha256` | 파일이 변조되지 않았는지 확인하는 체크섬 |

## 설치

- **PC:** `RemoteWindow-Setup-<버전>.exe` 를 실행합니다. 처음 실행하면 비밀번호를 정하는 창이 뜨고, 트레이 아이콘이 생깁니다.
- **폰:** `RemoteWindow-<버전>.apk` 를 폰에서 받아 설치합니다("출처를 알 수 없는 앱" 허용이 필요할 수 있습니다).
  PC 트레이의 **폰 연결…** 에 나오는 QR 을 폰 카메라로 찍으면 연결됩니다.

## 업데이트

- **PC:** 0.1.2 부터는 새 버전이 나오면 트레이 알림이 뜹니다. 트레이 메뉴 **새 버전 설치** 를 누르면
  설치 파일을 받아 체크섬을 확인한 뒤 설치합니다. 설정·비밀번호·연결 정보는 그대로 유지됩니다.
  0.1.1 이하는 새 설치 파일을 그대로 실행하면 됩니다.
- **폰:** 새 APK 를 그 위에 설치하면 저장된 PC·로그인이 유지됩니다.
  단, **0.6.0 이하에서 0.7.0 으로 올릴 때는 한 번만 앱을 지우고 설치**해야 합니다(서명 키 변경). 설치 후 PC 를 다시 연결하세요.

## 체크섬 확인 (선택)

```bat
certutil -hashfile RemoteWindow-Setup-0.1.2.exe SHA256
```
결과가 같은 이름의 `.sha256` 파일 내용과 같으면 정상입니다.

## 보안

- 같은 네트워크에서는 PC 마다 만든 인증서로 암호화(HTTPS)하고, 처음 연결할 때 인증서 지문을 확인합니다.
- 다른 곳(인터넷 너머)에서 접속할 때는 [Tailscale](https://tailscale.com) 을 쓰세요. 공유기 포트포워딩으로 직접 열지 마세요.
- 실행 중에는 트레이 아이콘이 항상 보이고, 원격으로 조작 중이면 화면에 표시됩니다.
